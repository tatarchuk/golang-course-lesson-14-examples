Slide 8: the WebSocket handshake by hand with curl, against the slide code as written (step 1.5).
Server: bin/libratrack-as-on-slides (= go run ./cmd/libratrack), 127.0.0.1:8080, allowed origin http://localhost:8080.
The request carries the slide's sample Sec-WebSocket-Key; the 101 answer must carry the slide's Sec-WebSocket-Accept.
After 101 the socket speaks WebSocket frames, so curl just waits for data until --max-time ends it (exit 28).
The token never appears below: the shell variable holds it.
